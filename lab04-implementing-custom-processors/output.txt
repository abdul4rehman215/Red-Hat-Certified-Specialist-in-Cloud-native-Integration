Debugging & Troubleshooting Notes (quick realism checks)
------------------------------------------------------

✅ Common mistakes I avoided / fixed while doing lab:
• Package name must match folder paths exactly (com/alnafi/camel/lab4/...)
• If logs look too quiet, check you are using slf4j-simple (we did)
• If mvn exec:java complains in some environments, you can add exec-maven-plugin to pom — but in this cloud machine it ran fine
