* Users:

  * `https://jsonplaceholder.typicode.com/users`

These endpoints return predictable JSON, making them ideal for integration testing.

## 🧩 What I Built

A Camel-based **REST consumer application** that:

* Periodically calls external APIs (via `timer:`)
* Logs request/response outcomes (status codes, routing paths)
* Transforms response JSON using a custom Processor:

  * adds metadata (`processedAt`, `source`)
  * transforms titles to uppercase
  * calculates body word count
  * assigns categories based on business logic
  * derives `emailDomain` and builds `fullAddress` for users
* “Stores” processed output using simulated database operations (printed inserts)
* Includes monitoring routes:

  * health checks
  * response time tracking
  * context statistics
